# Probability and Statistics

> Master concepts of statistical data analysis, probability theory and statistical inference to
> understanding and applying such concepts to solve real-life problems in engineering and science.

## Project - Statistical Computing & Data Analysis

### Goal
Develop a unified collection of statistical analysis exercises implemented in R, covering
simulation methods, hypothesis testing, maximum likelihood estimation, confidence intervals,
and data visualization. Shows reproducible workflows using real datasets, structured notebooks,
and clean statistical reasoning across a diverse set of applied problems.
